ゲーム用リポジトリの作成と公開

このページでやること

  1. テンプレートをコピーして、ゲーム用のリポジトリを作る
  2. GitHub Pages で公開して、スマホで遊べるようにする

目安：5〜10分　／　小さい文字の「補足」と、▶ で開く説明は読み飛ばしてもOKです。

リポジトリ・テンプレートとは？知っておくと安心

リポジトリは、GitHub の中の「保管箱」です。1つのリポジトリに、ゲームを1本入れます。

テンプレートは、ゲーム作りに必要なフォルダや Claude 用のルール（CLAUDE.md）、サンプルゲームが入った「ひな形」です。

フォルダ・ファイル入っているもの
www/ゲーム本体（Android アプリにするときは、このフォルダが使われます）
docs/ゲーム企画書、素材の出典、Android 化メモ
tools/動作確認の道具（Claude が使います）
CLAUDE.mdClaude が守る作業ルール

1. テンプレートからリポジトリを作る

  1. GitHub にログインした状態で、上のボタンからテンプレートのページを開きます。

  2. 右上の緑色の Use this template を押し、Create a new repository を選びます。

  3. 作成画面が開いたら、次の ①〜③ を順に操作します。

    • ①Repository name に名前を入力します（例：star-jump）。
    • ②Choose visibility は Public（公開）のままにします。
    • ③Create repository を押します。

    名前は半角英数字とハイフン（-）で付けます。ゲームの公開アドレスにも使われます（例：https://ユーザー名.github.io/star-jump/）。

    無料プランで GitHub Pages を使うには、Public にする必要があります。Public のリポジトリは、ゲームのファイルを誰でも見られる状態になります。

2. GitHub Pages で公開する

作ったリポジトリを公開して、ゲームをブラウザで遊べるようにします。最初に1回だけ設定すれば、そのあとは Claude が保存するたびに自動で更新されます。

  1. 作ったリポジトリのページで、上の Settings を押します。

    見つからないときは、… のメニューの中にあります。

  2. 左のメニューの Pages を押します。

  3. 「Build and deployment」の「Source」で Deploy from a branch を選びます。

  4. ブランチで main、フォルダで / (root) を選び、Save を押します。

  5. 数分待ってから、https://ユーザー名.github.io/リポジトリ名/ をスマホやパソコンで開きます。サンプルゲーム「ほしあつめ」が遊べれば成功です。

    反映には数分かかることがあります。設定画面を再読み込みすると、上のほうに公開アドレスが表示されます。手順は GitHub公式ドキュメント ↗ にもとづいています。

公開アドレスをスマホのブックマークやホーム画面に追加しておくと、遊んで確かめるのが楽になります。
