代表者への引き渡し

このページでやること

  1. 引き渡しの前に、Claude にチェックしてもらう
  2. リポジトリを代表者に移管する（引っ越し）
  3. 移管のあとの確認

ゲームが「ある程度できた」とチームで決めたら進めます。小さい文字の「補足」と、▶ で開く説明は読み飛ばしてもOKです。

1. 引き渡しの前のチェック

Android アプリにする前に、問題がないか Claude に確認してもらいます。

素材の出典と企画書も確認する

2. リポジトリを移管する

GitHub の「リポジトリの移管（Transfer）」を使うと、変更の履歴ごと、リポジトリを代表者のアカウントに引っ越しできます。

  1. ゲームのリポジトリの Settings を開き、いちばん下の「Danger Zone」までスクロールします。

  2. Transfer を押し、画面の案内に従って、移管先（代表者のユーザー名、またはチームの Organization 名）などを入力して確定します。

    確認のため、リポジトリ名の入力を求められることがあります。画面の表記は変わることがあります。手順は GitHub公式ドキュメント ↗ にもとづいています。

  3. 代表者の個人アカウントに移す場合は、代表者に届く確認メールで、1日以内に承認してもらいます。

移管先に同じ名前のリポジトリがあると、移管できません。

名前がかぶる場合は、先にどちらかのリポジトリ名を変えておきます。Organization に移す場合は、その Organization でリポジトリを作れる権限が必要です。

3. 移管のあとの確認

  • あなたは、そのまま共同作業者（Collaborator）として残ります。引き続き、ゲームのファイルを見たり変更したりできます。
  • 公開アドレスは引き継がれません。代表者側で GitHub Pages を設定し直すと、新しいアドレス（https://代表者のユーザー名.github.io/リポジトリ名/）で遊べるようになります。
  • 移管後も Claude Code で作業を続けるには、代表者（Organization の場合はその管理者）に、Claude の許可の設定（Claude GitHub App）にそのリポジトリを含めてもらいます。

Android アプリ化の手順は、ゲームのリポジトリの docs/android.md（代表者向けメモ）にまとめています。詳しくは Capacitor 公式ドキュメント（英語）↗ を参照してください。

チームで Organization を使う（これからの選択肢）

GitHub の Organization は、チームでリポジトリを共有するためのアカウントです。チームの Organization を作っておくと、メンバーが最初から Organization の中にゲームのリポジトリを作れるので、移管（引っ越し）が不要になります。

Organization を使う場合に知っておくこと代表者向け
  • Organization は代表者が作り、メンバーを招待します。無料のプランもあります（GitHub公式ドキュメント ↗）。
  • メンバーが Organization の中にリポジトリを作れるよう、Organization の設定を確認しておきます。
  • Claude Code で作業するには、Organization の管理者が Claude GitHub App を Organization に許可します（メンバーが申請し、管理者が承認する形になることもあります）。
  • GitHub Pages を 非公開（Private）リポジトリで使いたい場合は、Organization 側の有料プランが必要です。代表者の個人アカウントの有料プランは、Organization には適用されません。公開（Public）リポジトリなら無料で使えます。
  • メンバーは、テンプレートの Use this template の作成画面で、Owner（持ち主）を Organization にしてリポジトリを作ります。
