Androidストアリリース対応
（けんちくぶ！への引き渡し）

このページは、Google Play などでアプリとしてリリースしたいときだけ行います。ブラウザで遊べるゲームを作るだけなら、読まなくて大丈夫です。

このページでやること

  1. 引き渡しの前に、Claude にチェックしてもらう
  2. リポジトリを「けんちくぶ！」に移管する（引っ越し）
  3. 移管のあとの確認

Android アプリ化とストアへのリリースは、「けんちくぶ！」が行います。小さい文字の「補足」と、▶ で開く説明は読み飛ばしてもOKです。

1. 引き渡しの前のチェック

Android アプリにする前に、問題がないか Claude に確認してもらいます。

素材の出典と企画書も確認する

2. リポジトリを「けんちくぶ！」に移管する

GitHub の「リポジトリの移管（Transfer）」を使うと、変更の履歴ごと、リポジトリを「けんちくぶ！」の GitHub アカウントに引っ越しできます。

  1. 移管先にする「けんちくぶ！」の GitHub ユーザー名を、チームで確認しておきます。

  2. ゲームのリポジトリの Settings を開き、いちばん下の「Danger Zone」までスクロールします。

  3. Transfer を押し、画面の案内に従って、移管先のユーザー名などを入力して確定します。

    確認のため、リポジトリ名の入力を求められることがあります。画面の表記は変わることがあります。手順は GitHub公式ドキュメント ↗ にもとづいています。

  4. 「けんちくぶ！」に確認メールが届くので、1日以内に承認してもらいます。

移管先に同じ名前のリポジトリがあると、移管できません。

名前がかぶる場合は、先にリポジトリ名を変えておきます。

3. 移管のあとの確認

  • あなたは、そのまま共同作業者（Collaborator）として残ります。引き続き、ゲームのファイルを見たり変更したりできます。
  • 公開アドレスは引き継がれません。「けんちくぶ！」側で GitHub Pages を設定し直すと、新しいアドレスで遊べるようになります。
  • 移管後も Claude Code で作業を続けるには、「けんちくぶ！」に、Claude の許可の設定（Claude GitHub App）にそのリポジトリを含めてもらいます。

Android アプリ化の手順は、ゲームのリポジトリの docs/android.md（アプリ化メモ）にまとめています。詳しくは Capacitor 公式ドキュメント（英語）↗ を参照してください。
