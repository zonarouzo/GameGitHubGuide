ClaudeとGitHubではじめるブラウザゲーム開発

ゲームを作る・遊んで確かめる

いつもの流れ

  1. Claude Code を開いて、ゲームのリポジトリを選ぶ
  2. やりたいことを日本語で頼む（下のプロンプト例を使えます）
  3. 報告の「遊んで確かめる」のアドレスで遊ぶ → 気になったことをまた頼む

このページは、必要なところだけ読めばOKです。小さい文字の「補足」と、▶ で開く説明は読み飛ばしても大丈夫です。

1回の依頼では、1つのことだけ頼むのがコツです。

いくつもまとめて頼むと、どの変更で何が変わったのかわかりにくくなります。「ジャンプを追加」→ 遊ぶ →「ジャンプを高く」のように、少しずつ進めましょう。

プロンプトの【 】の部分は、自分の内容に書き換えて使ってください。ふだんの言葉で頼んでも大丈夫です。保存は Claude が自動で行います。

機能を追加する

画面を追加したいとき・アイデアを出してもらいたいとき

調整する

数値を変えたいとき・操作の手ざわりを良くしたいとき

見た目・音を変える

自分で用意した画像を使いたいとき・効果音を付けたいとき

画像は、Claude Code の入力欄に添付して頼めます。

人が作った素材（フリー素材など）を使うときは、利用条件（商用利用・アプリでの配布ができるか）を必ず確認してください。Claude は、出典を素材の記録（docs/credits.md）に残します。

遊んで確かめる

  1. Claude の報告の「遊んで確かめる」のアドレスを、スマホやパソコンで開きます。

    保存から反映まで数分かかることがあります。前のままのときは、少し待ってからページを再読み込みしてください。

  2. 気になったことを、そのまま Claude に伝えます。

不具合を直してもらう

「何が起きたか」「どの端末で」「どうやったら起きるか」を伝えると、直してもらいやすくなります。

全体をチェックしてもらいたいとき

企画書を整える

Claude は、ゲーム企画書（docs/design.md）を読んでから作業します。決まったことがたまってきたら、企画書を今のゲームに合わせてもらいましょう。

元に戻す

もっと前の状態に戻したいとき

GitHub でリポジトリを開き、ファイル一覧の上にある時計のマーク（変更の履歴）からも、いつ何を変えたかを確認できます。

保存について

Claude が作業のたびに、自動で main（メインの保存場所）に反映します。報告の「保存の状況」に「main に反映しました」とあれば完了です。

「main に反映できませんでした」と報告されたとき

作業内容は「作業用の保存場所（ブランチ）」には保存されています。次の手順で、手動で main に反映できます。

  1. Claude Code の画面で Create PR を押します。
  2. 表示されたリンクから GitHub のページを開き、Merge pull request を押します。
  3. Confirm merge を押します。

ほかの指示の例は プロンプト集 にまとめています。
