このページでやること

  1. 始め方を選んで、サンプルゲームを自分のゲームに置き換える

  2. スマホで遊んでみる

目安：10〜30分　／　小さい文字の「補足」と、▶ で開く説明は読み飛ばしてもOKです。

ステップ3で接続を確かめると、Claude が「初期設定」を提案して、始め方を聞いてきます。同じ会話のまま、どちらかを選んで進めます。

A. 新しく作る

  1. 始め方を聞かれたら「新しく作ります」と答えます。

  2. 作りたいゲーム（タイトル・ジャンル・画面の向き・操作・ルールなど）を、わかる範囲で答えます。

    決まっていないことは「おまかせ」「未定」で大丈夫です。あとからいくらでも変えられます。「〇〇みたいな雰囲気」のように、たとえで伝えるのもおすすめです。

  3. サンプルゲームを置き換えてよいか聞かれたら、「置き換えてOKです」と答えます。

  4. Claude の報告の「保存の状況」に「main に反映しました」とあれば完了です。スマホで遊んでみましょう。

    Claude は保存の前に、ゲームを自分で開いてエラーがないか確かめています。報告の「動作確認」に結果が書かれます。

Claude が初期設定を提案してこないとき・新しい会話で始めるとき

次の文章を送ると、初期設定が始まります。【 】の部分を書き換えてから送ってください（【 】の記号ごと消します）。

B. Claude のチャットで途中まで作ったゲームを移す

普通の Claude のチャット（Claude Code ではないほう）で作ったゲームを、HTML ファイルとしてダウンロードして、Claude Code に渡します。移したあとは、Claude Code で続きを作れます。

  1. 普通の Claude のチャットで、ゲームを作った会話を開き、① ゲームのファイル（「コード・HTML」と書かれた枠）を押します。

  2. ② 右上の ︙ を押し、③ ダウンロード を押します。

    パソコンのブラウザなど、使っている画面によってボタンの場所が違うことがあります。ファイル名の最後が .html になっていれば大丈夫です。

  3. Claude Code に戻り、入力欄の ＋ から、ダウンロードしたファイルを添付して、次の文章を送ります。

    Claude Code が初期設定の始め方を聞いてきた場合は、「B」と答えてから添付しても大丈夫です。

  4. Claude が「アプリにしやすい形にするための直し」を説明してきたら、内容を見て「進めてOKです」と答えます。

    ネット上の部品を読み込んでいる場合や、React などの特別な仕組みで作られている場合は、普通の形に書き直す必要があります。書き直しが大きいときは、作業の前に Claude が説明してくれます。

  5. 報告に書かれた「元のゲームから変わった点」を確認し、遊んで確かめます。

    元のファイルの控えは import/ フォルダに保存されます。うまく動かないところがあれば、「元のゲームでは〇〇だったのに、△△になっている」と伝えると直してもらえます。

チャットにゲームのファイルが見当たらないとき・ダウンロードできないとき

普通の Claude のチャットで次の文章を送ると、ゲームを1つの HTML ファイルにまとめてもらえます。そのあと、上の手順でダウンロードします。

ファイルを添付できない場合は、表示されたコードを全部コピーして、次の文章の【 】に貼り付けて送る方法もあります。コードが途中で切れていないか注意してください。

初期設定で Claude がすること知っておくと安心
  • ゲーム企画書（docs/design.md）を、あなたのゲームの内容で書き直す
  • サンプルゲームを、あなたのゲームに置き換える（A は最初の遊べる形を作る、B は移したゲームをアプリにしやすい形に整える）
  • スマホ・パソコンの画面で、エラーがないか確かめる
  • GitHub のメインの保存場所（main）に反映する

最初から完成形を目指さず、遊びながら少しずつ育てていくのがコツです。

スマホで遊んでみる

  1. 数分待ってから、公開アドレス（https://ユーザー名.github.io/リポジトリ名/）をスマホで開きます。

    Claude の報告の「遊んで確かめる」にもアドレスが書かれています。サンプルゲームのままだったら、少し待ってからページを再読み込みしてください。

  2. 遊んでみて、気になったことをメモしておきます。次のページで、Claude に直してもらいます。
