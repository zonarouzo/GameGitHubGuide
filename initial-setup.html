ClaudeとGitHubではじめるブラウザゲーム開発

ゲームの初期設定

このページでやること

  1. Claude の質問に答えて、サンプルゲームを自分のゲームに置き換える
  2. できた最初の形を、スマホで遊んでみる

目安：10〜20分　／　小さい文字の「補足」と、▶ で開く説明は読み飛ばしてもOKです。

1. Claude の質問に答える

ステップ3で接続を確かめると、Claude が「初期設定」を提案して、作りたいゲームについて質問してきます。同じ会話のまま答えていきます。

  1. 作りたいゲーム（タイトル・ジャンル・画面の向き・操作・ルールなど）を、わかる範囲で答えます。

    決まっていないことは「おまかせ」「未定」で大丈夫です。あとからいくらでも変えられます。「〇〇みたいな雰囲気」のように、たとえで伝えるのもおすすめです。

  2. サンプルゲームを置き換えてよいか聞かれたら、「置き換えてOKです」と答えます。

  3. Claude の報告の「保存の状況」に「main に反映しました」とあれば完了です。

    Claude は保存の前に、ゲームを自分で開いてエラーがないか確かめています。報告の「動作確認」に結果が書かれます。

Claude が初期設定を提案してこないとき・新しい会話で始めるとき

次の文章を送ると、初期設定が始まります。【 】の部分を書き換えてから送ってください（【 】の記号ごと消します）。

初期設定で Claude がすること知っておくと安心
  • あなたの答えをもとに、ゲーム企画書（docs/design.md）を書き直す
  • サンプルゲームを、あなたのゲームの最初の遊べる形（小さくてOK）に作り直す
  • スマホ・パソコンの画面で、エラーがないか確かめる
  • GitHub のメインの保存場所（main）に反映する

最初から完成形を目指さず、小さく作って遊びながら育てていくのがコツです。

2. スマホで遊んでみる

  1. 数分待ってから、公開アドレス（https://ユーザー名.github.io/リポジトリ名/）をスマホで開きます。

    Claude の報告の「遊んで確かめる」にもアドレスが書かれています。サンプルゲームのままだったら、少し待ってからページを再読み込みしてください。

  2. 遊んでみて、気になったことをメモしておきます。次のページで、Claude に直してもらいます。
