ClaudeとGitHubではじめるブラウザゲーム開発（けんちくぶ！）

よくある質問・トラブル解決

困ったときは、まずここを確認してください。質問をクリックすると答えが開きます。

公開・遊ぶとき

リポジトリを Public（公開）にして大丈夫？

Public にすると、ゲームのファイル（プログラムや画像）を誰でも見られる状態になります。無料プランで GitHub Pages を使うには Public にする必要があります。

見られて困る情報（本名、パスワード、未発表の秘密の設定など）は、ゲームのファイルや企画書に書かないようにしましょう。

公開アドレスを開いても「404」と表示される
  1. GitHub Pages の設定（Deploy from a branch・main・/ (root)）ができているか確認します。
  2. 設定してから数分は表示されないことがあります。少し待ってから再読み込みします。
  3. アドレスのユーザー名・リポジトリ名が合っているか確認します。リポジトリの Settings → Pages の上のほうに、正しいアドレスが表示されます。
Claude が直したのに、遊ぶと前のままになっている

反映まで数分かかることがあります。少し待ってから、ページを再読み込みしてください。それでも変わらない場合は、Claude の報告で「main に反映しました」となっているか確認してください。

スマホで音が出ない

スマホのブラウザは、画面を一度タップするまで音を鳴らせない決まりがあります。ゲームを始めるときに一度タップしてから確認してください。スマホがマナーモードになっていないかも確認しましょう。それでも鳴らない場合は、不具合として Claude に伝えてください。

Claude の使い方

Claude の利用制限に達したら？

Claude Code の利用量は、ふつうの Claude チャットと同じプランの利用上限に含まれます。上限に達したら、画面に表示される再開時刻まで待ってください。それまでに保存されたゲームは GitHub に残っています。大きな機能を一度に頼むより、少しずつ頼むほうが利用量を抑えられます。

Claude との会話を新しくしても大丈夫？

大丈夫です。ゲームは GitHub に保存されていて、Claude は作業のたびに最新の状態を取り込みます。会話の内容は引き継がれないので、新しい会話の最初に次のように頼むと、今の状態を確認できます。

ゲームを2本目、3本目と作りたい

ゲームごとに、テンプレートから新しいリポジトリを作ります（1リポジトリ＝1ゲーム）。Claude への許可を「すべてのリポジトリ」にしていれば、新しいリポジトリもすぐ Claude Code で選べます。

別のパソコンやスマホでも作業できる？

できます。GitHub と Claude にログインすれば、どのパソコンでも同じように作業できます。Anthropic の案内では、Claude のスマホアプリからも Claude Code の作業を始めたり、様子を確認したりできるとされています。

素材・アプリ化

ネットで見つけた画像や音を使っていい？

利用条件を確認して、アプリとして配布（商用を含む）できるものだけを使ってください。条件がわからないものや、既存のゲーム・アニメのキャラクターなどは使えません。使った素材の出典は、Claude が docs/credits.md に記録します。

ゲームに広告を入れたい

「広告を見ると報酬がもらえる」機能（リワード広告）は、開発中はチームのハウス広告で仮組みします。Claude に頼めば、テンプレートに入っている部品を組み込んでくれます。本物の広告への差し替えは、「けんちくぶ！」がアプリ化のときに行います。

自分で Android アプリにできる？

Android アプリにするには、パソコンに開発ツール（Android Studio など）を入れる作業が必要です。このサイトでは、「けんちくぶ！」がまとめてアプリ化する流れにしています（Androidストアリリース対応）。手順は、ゲームのリポジトリの docs/android.md にまとめています。

iPhone のアプリにもできる？

このテンプレートは Android アプリ化を想定しています。iPhone で遊ぶだけなら、公開アドレスを Safari で開けば遊べます。

用語

PR（プルリクエスト）やブランチとは何？

ブランチは、リポジトリの中の「作業用の保存場所」です。メインの保存場所は main です。PR（プルリクエスト）は、作業用の保存場所の変更を main に取り込むための申請です。

このテンプレートでは、Claude が作業内容を直接 main に反映するので、ふだんは意識する必要はありません。反映できなかったときだけ、手動で反映する方法を使います。

CLAUDE.md とは？

Claude が作業するときに守るルールを書いたファイルです。アプリ化しやすい作り方や、保存の前の動作確認などが書かれています。ふだんは触る必要はありません。
