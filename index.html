ClaudeとGitHubではじめる
ブラウザゲーム開発

「こんなゲームにしたい」と日本語で頼むだけ。
作ったゲームはすぐスマホで遊べて、あとから Android アプリにもできます。

はじめる

必要なもの

  • Claude Pro の契約（Max などの上位プランでもOK）
  • パソコンとブラウザ（Chrome、Edge、Safari など）
  • メールアドレス（GitHub の登録に使います。GitHub は無料です）
  • スマホ（作ったゲームを遊んで確かめるのに便利です）

パソコンにソフトをインストールする必要はありません。Android アプリ化だけは、チームの代表者がパソコンで行います。

はじめるまでの流れ

上から順番に進めてください。各ページの最後で「完了」にチェックすると、ここに進み具合が表示されます。

  1. 1. GitHubアカウントの作成
  2. 2. ゲーム用リポジトリの作成と公開
  3. 3. Claude Codeとの連携
  4. 4. ゲームの初期設定
  5. 5. ゲームを作る・遊んで確かめる
  6. 6. 代表者への引き渡し

困ったときは よくある質問・トラブル解決、よく使う指示は プロンプト集 へ。

できるようになること

🎮

話しかけるだけでゲームが育つ

「敵を出して」「もう少し簡単に」と頼むと、Claude がゲームを作り直します。

📱

すぐスマホで遊べる

GitHub Pages で公開されるので、アドレスを開けばスマホでもパソコンでも遊べます。

🧪

壊れにくい

Claude は保存する前に、ゲームを自分で開いてエラーがないか確かめます。変更の履歴も残ります。

🤖

そのまま Android アプリへ

はじめからアプリにしやすい作りなので、できあがったら代表者に渡すだけです。

小説の執筆・管理には、姉妹サイト ClaudeとGitHubではじめる小説管理 をどうぞ。
